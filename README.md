# LIYAB — Personal Expense Tracker

> **LIYAB — List, Identify, Yield, Analyze, Budget**
> A simple personal expense tracking application designed to help users understand and manage their everyday spending.

## 📌 About the Project

**LIYAB** is a personal expense tracker built to make recording and understanding daily expenses simple.

Instead of relying on handwritten notes or spreadsheets, LIYAB provides a dedicated application where users can record their expenses, organize them, and review their spending habits.

The project is also a learning project for practicing **HTML, CSS, JavaScript, and mobile application development using Capacitor**.

## 🎯 Project Goals

* Make recording daily expenses quick and simple
* Help users understand where their money is going
* Organize expenses by categories
* Provide useful spending summaries
* Encourage better budgeting habits
* Practice modern web development and application packaging

## ✨ Features

### 💰 Expense Recording

Users can record information about their expenses, such as:

* Expense name
* Amount
* Category
* Date
* Optional notes

### 🗂️ Expense Categories

Expenses can be organized into categories such as:

* 🍔 Food
* 🚗 Transportation
* 📚 Education
* 🛒 Shopping
* 💡 Bills & Utilities
* 🎮 Entertainment
* 📦 Others

### 📊 Expense Summary

The application can provide an overview of spending, including:

* Total expenses
* Daily spending
* Monthly spending
* Spending by category
* Recent transactions

### 🔎 Expense Management

Users can:

* View recorded expenses
* Edit expenses
* Delete expenses
* Search or filter transactions

### 💾 Local Data

The initial version is designed to work without requiring a traditional database server.

Expense information can be stored locally on the device, making the application suitable for personal use and offline scenarios.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm
* Capacitor
* Android Studio
* Android SDK
* Git

### Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/liyab-personal-expense-tracker.git
```

Enter the project directory:

```bash
cd liyab-personal-expense-tracker
```

### Install Dependencies

```bash
npm install
```

### Build the Web Application

```bash
npm run build
```

### Sync With Android

```bash
npx cap sync android
```

### Open in Android Studio

```bash
npx cap open android
```

From Android Studio, you can run the application on an Android device or emulator and build an APK.
